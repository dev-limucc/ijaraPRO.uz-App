# ijaraPRO.uz

Rental (ijara) platform for Uzbekistan — find and list rental properties with a web frontend, a Telegram bot, and a shared backend.

## Structure

| Folder | What it is |
|---|---|
| `frontend/` | Web app UI |
| `backend/` | API server |
| `bot/` | Telegram bot interface |
| `db/` | Database schema / storage |

## Status

Early-stage project; not production-ready. Licensed under [MIT](LICENSE).
